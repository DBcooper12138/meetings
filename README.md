# 会议发布与参会确认系统（v2 多用户版）

每个用户用自己的账号登录，各自发布会议、各自维护名单、各自看统计。
参会人不需要注册，凭链接填姓名确认是否参会。超级管理员统一管理用户、套餐、充值和全部会议。

**完整说明请先看：[docs/部署与使用手册.md](docs/部署与使用手册.md)**

---

## 三步跑起来

| 步骤 | 做什么 | 在哪做 |
| --- | --- | --- |
| **1. 建数据库** | 在 [supabase.com](https://supabase.com) 免费注册 → 新建项目（区域选 Singapore）→ 把 `supabase/01_schema.sql` **整段**粘进 SQL Editor 执行 | Supabase 网页 |
| **2. 填参数** | 把 Supabase 的 `Project URL` 和 `anon public` 密钥填进 `config/config.js` | 记事本 |
| **3. 发布** | 整个文件夹（**不含 `_dev`**）上传到 GitHub 仓库 → Settings → Pages → 选 `main` + `/ (root)` → 得到 `https://用户名.github.io/仓库名/` | GitHub 网页 |

然后：
1. 打开网址 → **注册**（工号+姓名+手机号+邮箱+密码）→ 验证邮箱 → 登录
2. 在 Supabase 里执行一句 `update public.profiles set is_super = true where emp_no = '你的工号';`，刷新网页即可看到「超级管理员」
3. 名单管理 → 写入初始 55 人名单 → 发布会议 → 复制链接发群

> **还必须在 Supabase 里配两样东西**，否则注册/改密码的邮件跳不回来：
> - `Authentication → URL Configuration`：Site URL 填你的 Pages 网址，Redirect URLs 加 `https://用户名.github.io/仓库名/**`
> - 建议配自定义 SMTP（自带邮件每小时只能发几封）——**顺带解锁邮件模板编辑**；不配也能用，走邮件里的链接即可，只是邮件里没有 6 位验证码

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 账号体系 | 工号+姓名+手机号+邮箱注册；邮箱链接/验证码验证；邮箱验证码重置密码 |
| 数据隔离 | 每个用户的名单、会议、统计互不可见（数据库 RLS 强制） |
| 发布会议 | 按类别整类勾选 + 搜索单独挑人；生成链接/二维码/催办文本 |
| 参会填报 | 参会人免登录，填姓名 → 参加/不参加 → 原因/备注；截止前可改 |
| 名单管理 | 工号 + 姓名 + 类别 + 部门；Excel/CSV 导入导出（工号在姓名前） |
| 统计面板 | 按会议统计；按人员统计（总参会次数、请假次数、未确认、出席率、逐场明细）；五种导出 |
| 我的账户 | 套餐卡片、余额、账单流水、充值申请（提交→管理员审批入账） |
| 超级管理员 | 用户管理（改信息/锁定/设超管/调余额/赠套餐）、套餐定价、充值审批、全部会议总览 |

## 计费规则

按**套餐时长**计费：买月卡 30 天内发布会议不限场次；到期后可继续用已有会议，但不能发新会议。
套餐价格与有效期由超管在「套餐定价」里改。目前未接在线支付，充值走"用户申请 → 超管审批入账"。

## 技术说明

- 纯静态前端：HTML + CSS + 原生 JS，无构建步骤、无框架，改完直接上传
- 账号与数据：Supabase（Auth + PostgreSQL），权限由数据库行级安全策略强制
- 唯一外部依赖是 Supabase 客户端库（CDN）；**Excel 读写和二维码生成都是自己实现的**，断网也能用
- 未配置 Supabase 时会进入「本机演示模式」，方便离线试用与自动化测试
